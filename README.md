# World Shaper

**Atelier de mondes Minecraft** : sculpter, peindre et exporter des mondes Java (1.21.1) et Bedrock,
dans l'esprit de WorldPainter, en plus rapide et plus moderne.

> Le code source n'est pas encore public. Ce dépôt sert à échanger avec la communauté :
> questions, signalements de bugs, idées de fonctionnalités et contributions (traductions,
> documentation, exemples).

## Participer

| Vous voulez… | Où aller |
|---|---|
| Poser une question | [Discussions → Questions](../../discussions/categories/q-a) |
| Signaler un bug | [Nouveau signalement](../../issues/new?template=bug.yml) |

Avant d'ouvrir un signalement, cherchez s'il existe déjà dans les [issues](../../issues).

## En bref

- Pinceaux de relief (monter, lisser, aplanir, éroder, montagnes…) avec clic tenu, pinceaux image
- Calques : matériaux, biomes, forêts, plantes, grottes, minerais, eau et lave, objets
- Relief procédural par graphe de nodes, mondes tirés d'un lieu réel, images de référence
- Hauteur de monde de −2032 à 2032, blocs moddés, scripts (y compris ceux de WorldPainter)
- Export Java 1.21.1 et Bedrock, fusion avec un monde existant

# World Shaper (English)

**A Minecraft world workshop**: sculpt, paint and export Java (1.21.1) and Bedrock worlds, in the
spirit of WorldPainter, faster and more modern.

The source code is not public yet. This repository is for the community: questions
([Discussions](../../discussions/categories/q-a)), [bug reports](../../issues/new?template=bug.yml),
[feature ideas](../../issues/new?template=idee.yml) and contributions (translations, docs, examples —
see [CONTRIBUTING.md](CONTRIBUTING.md)).
