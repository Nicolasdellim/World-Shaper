# Contribuer à World Shaper

Merci de votre intérêt ! Le code source n'est pas encore publié : les pull requests portent pour
l'instant sur ce qui vit dans ce dépôt.

## Ce que vous pouvez proposer par pull request

- **Documentation** : guides, astuces, corrections (dossier `docs/`).
- **Traductions** : textes de l'interface dans une nouvelle langue (dossier `translations/`,
  un fichier par langue, à partir du modèle anglais quand il sera publié).
- **Exemples** : scripts, recettes, préréglages de nodes, pinceaux dont vous êtes l'auteur
  (dossier `exemples/`, avec la licence de votre choix indiquée).

## Ce qui passe par les issues

- **Bugs** : formulaire « Signaler un bug » (version, système, étapes pour reproduire, fichiers).
- **Idées** : formulaire « Proposer une idée » (le besoin d'abord, la solution ensuite).

## Règles simples

- Une pull request = un sujet.
- Ne déposez que des fichiers dont vous avez les droits (pas de pinceaux ou d'objets d'autrui).
- Écrivez en français ou en anglais.

---

**English**: the source code is not public yet. Pull requests are welcome for documentation,
translations and examples you authored. Bugs and ideas go through the issue forms.
